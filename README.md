# Todo List App

A simple browser-based todo list built with HTML, CSS, and JavaScript. Tasks are stored in the browser using `localStorage`, so they remain available after a page refresh in the same browser.

## Features

- Add a task
- View the number of pending tasks
- Delete an individual task
- Clear all tasks
- Persist tasks with browser `localStorage`

## Built with

- HTML
- CSS
- JavaScript
- Browser localStorage

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/coudharyprince/lgmtask1.git
   ```
2. Open `Todo List App - JavaScript/index.html` in a browser.

No build step or package installation is required.

## Project notes

This is a small front-end learning project. The page uses Font Awesome icons from a CDN. Do not enter sensitive information: tasks are stored locally in the browser.
